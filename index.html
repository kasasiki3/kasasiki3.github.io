構成

面以外を全部作る。

おうち太鼓は7つの部品でできています。このうち面（打面）は用意しなければなりません。

  1. 01面既製品AC面 / 太鼓フォース面を流用（AC基盤との互換性なし）
  2. 02上板・下板・足ラワンベニヤ12mm。実寸図面をA4で印刷して切り出す
  3. 03防振ゴム・ネジVD2-2015M6 ×14／M6ネジ・ナット・ワッシャー 各14
  4. 04スペーサー面と縁の高さ調整。0.2 / 0.4 / 0.6mm の3Dプリント品
  5. 05センサー ×4左縁・左面・右面・右縁。AT3040 または GSS-4SA
  6. 06センサー固定パーツAT3040用の3Dプリント品。M3L6ネジで固定
  7. 07接続器4本のセンサーを受けてPCへキー入力を送る。最安800円

02〜04 が太鼓基盤（木工）、05〜07 が信号まわり（電子工作）です。

接続器

注目はRP2040接続器。

接続器は、センサー4本の信号をPCへの入力に変換します。PCから見ると、これはただのUSBキーボード。叩けば D・F・J・K が打たれます。キーボードで遊べるゲームならそのまま使えます。

入力を守るクランプ回路

2本のショットキーバリアダイオード（D9・D10）が性能と安定感を上げています。

仕組み

振動の大きさではなく、振動の変化速度を見ている。

ピエゾが振動すると電流が発生します。マイコンは直前の電圧との差分（デルタ）を取り、設定した閾値（感度）を超えた瞬間にキーを送ります。急な立ち上がりだけを拾うので、隣の打点の余韻には反応しにくい。そのうえで誤検出を防ぐタイマー（Delay）を4種類持ち、入力後の一定時間は同センサーや隣接センサーからの入力を無視します。

  1. 01ピエゾ振動 → 電圧

    打面・縁の揺れを拾う

  2. 02ADC電圧 → 数値

    マイコンが読み取る

  3. 03差分検出数値 → Δ

    直前サンプルとの差を取る

  4. 04閾値判定Δ > 感度

    超えたら入力。Delayで二重反応を抑える

  5. 05キー入力D F J K

    HIDとしてPCへ送信

キー割り当ては自由

4つの打点に、好きなキーを割り当てられます。初期値は太鼓系で定番の D / F / J / K。使うゲームに合わせて変えてください。

左縁DFSXD初期値 D
左面FGDCF初期値 F
右面JHKNJ初期値 J
右縁KJLMK初期値 K

割り当ては接続器側に保存されるので、別のPCに挿しても同じ設定で使えます。

感度変更

感度はブラウザから変える。

閾値（感度）と4種類のDelay。この数値を、接続器をPCに繋いだままブラウザから書き換えられます。アプリのインストールも開発環境も要りません。叩きながら数値を詰めて、決まったら接続器のフラッシュに保存します。

センサー

まずは AT3040 から。

センサーはピエゾ素子（圧電素子）です。振動の大きさに応じて電圧を出す部品で、左縁・左面・右面・右縁の4箇所に仕込みます。おすすめのピエゾ素子（センサー）は2種類。どちらもしっかり固定すれば弱い力で反応します。性能は GSS-4SA が上で感度設定に余裕が生まれますが、価格差がかなり大きい。最初は AT3040 で十分です。

AC筐体で使われているセンサーです。組み立て手順は AT3040 と同じなので、そのまま置き換えられます。

センサーはケーブルをはんだ付けして4本作ります。赤いケーブルが＋。熱収縮チューブ（2.5mm）は10mmに切って使います。費用は 構成 の内訳にまとめてあります。

太鼓基盤

ベニヤ板を切って、2〜3時間で組む。

太鼓基盤は、面（打面）を載せてセンサーを仕込む土台です。12mm のラワンベニヤで作ります。

上板と下板のあいだに防振ゴムを14箇所入れて面を浮かせ、隣の打点へ振動が伝わるのを抑えています。

図面は A4用紙4枚分の実寸PDFです。印刷して貼り合わせれば、そのまま型紙になります。板はホームセンターのカットサービスに任せてもかまいません。
